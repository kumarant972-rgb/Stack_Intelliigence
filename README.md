# Stack Intelligence Freelance Website

This is a static portfolio website for Data Analysis, Python Development, and Web Design.

## Deploy on Netlify
1. Extract the ZIP.
2. Open https://app.netlify.com/drop
3. Drag the extracted folder into the upload area.

## Deploy on GitHub Pages
1. Upload `index.html` and the `assets` folder to a GitHub repository.
2. Open Settings > Pages.
3. Select the `main` branch and `/root`.
4. Save.

Replace `yourmail@example.com` in `index.html` with your real email address.
